1.2 Vstup do predmetu

V tomto predmete sa naučíš riešiť problémy algoritmicky a vytvárať programy v Pythone. Na začiatok pripravíme editor, Python a niekoľko ukážok, ktoré si môžeš hneď spustiť.

Cieľ hodiny

Žiak otvorí školský Visual Studio Code Portable z určeného priečinka, vyberie správny Python interpreter, spustí svoj prvý program a vie, kde kontrolovať aktualizácie editora a jeho rozšírení.

1. Visual Studio Code Portable v počítači

Na školských počítačoch používame prenosnú (portable) verziu VS Code v priečinku C:\Progs\VSC. Je to editor kódu. Samotný editor neobsahuje Python — interpreter sa inštaluje samostatne.

  1. Otvor oficiálnu stránku Visual Studio Code – Download a stiahni Windows ZIP archív zodpovedajúci počítaču (zvyčajne Windows x64).
  2. Rozbaľ obsah ZIP archívu do C:\Progs\VSC. Po rozbalení skontroluj, že sa v priečinku nachádza Code.exe.
  3. V tom istom priečinku vytvor podpriečinok s presným názvom data, teda C:\Progs\VSC\data. V portable režime sem VS Code ukladá nastavenia, profily a rozšírenia.
  4. Spusti C:\Progs\VSC\Code.exe. Pripni ho na panel úloh alebo vytvor odkaz, aby si ho vedel rýchlo otvoriť.
  5. V editore otvor svoj pracovný priečinok cez File → Open Folder…. Programovací súbor ulož s príponou .py, napríklad prvy_program.py.
Dôležité pri aktualizácii Portable: ZIP verzia sa neaktualizuje automaticky. Pravidelne skontroluj oficiálnu stránku VS Code. Pri aktualizácii zavri editor, stiahni a rozbaľ novú verziu, potom do jej priečinka prenes existujúci priečinok data (najprv si ho zálohuj). Spusti nový Code.exe a over, že sa zachovali nastavenia a rozšírenia.

2. Nainštaluj Python 3.12.10

Python nie je súčasťou VS Code. Pre tento kurz nainštaluj Python 3.12.10 pre Windows x64 z oficiálnej stránky vydania Python 3.12.10 (Windows installer 64-bit). Označenie je 3.12.10, nie 2.12.10. Túto konkrétnu verziu používame ako spoločnú kurzovú verziu kvôli prostrediu a Pygame.

  1. Spusti stiahnutý Windows inštalátor. Zaškrtni Add python.exe to PATH, ak sa táto voľba zobrazí, a pokračuj inštaláciou.
  2. Po inštalácii otvor nový terminál vo VS Code cez Terminal → New Terminal.
  3. Over verziu príkazom py -3.12 --version. Očakávaný výstup pri tejto kurzovej inštalácii je Python 3.12.10.
  4. Ak VS Code ešte nepozná interpreter, stlač Ctrl+Shift+P, zvoľ Python: Select Interpreter a vyber Python 3.12.
Poznámka pre učiteľa: Python 3.12.10 je posledná verzia radu 3.12 vydaná s klasickým Windows inštalátorom. Python.org odvtedy vydal aj 3.12.15 ako bezpečnostné vydanie iba so zdrojovými súbormi. Preto netvrďme, že 3.12.10 je najvyššia verzia, ktorú Pygame podporuje; je to konkrétna verzia zvolená pre jednotné školské prostredie. Pred kurzom overiť Pygame na školských počítačoch.

3. Základné rozšírenia pre Python

V paneli Extensions (ikona štvorčekov alebo Ctrl+Shift+X) vyhľadaj a nainštaluj tieto rozšírenia z Visual Studio Marketplace:

  • Python (Microsoft, ms-python.python) – základné spúšťanie, výber interpreteru a podpora Python projektov.
  • Pylance – dopĺňanie kódu, informácie o funkciách a zvýraznenie chýb. Často sa nainštaluje spolu s rozšírením Python.
  • Python Debugger – krokovanie programu a kontrola premenných. Aj toto rozšírenie môže Python nainštalovať automaticky ako doplnok.
  • Jupyter je voliteľné, ak budeme pracovať s notebookmi .ipynb; na obyčajné súbory .py ho na začiatok nepotrebuješ.

Pravidelné aktualizácie

Pravidelne aktualizuj samotný VS Code (Portable ZIP ručne podľa postupu vyššie) aj rozšírenia. Otvor Extensions a použi dostupné tlačidlo aktualizácie; nastavenie automatickej aktualizácie rozšírení nechaj zapnuté, ak správca počítača neurčil inak. Po aktualizácii reštartuj VS Code, ak si to vypýta. Rozšírenia inštaluj iba z oficiálneho Marketplace a kontroluj meno vydavateľa.

4. Prvý Python program – „Ahoj, svet!“

Vytvor súbor ahoj.py, napíš program a spusti ho tlačidlom Run Python File alebo ikonou ▶ vpravo hore.

print("Ahoj, svet!")

Príkaz print() zobrazí text v termináli.

5. Základné výpočty

Python pozná bežné matematické operácie: + sčítanie, - odčítanie, * násobenie, / delenie, // celočíselné delenie, % zvyšok po delení a ** umocnenie. Zátvorky určujú poradie výpočtu.

print(2 + 3)       # 5
print(10 - 4)      # 6
print(6 * 7)       # 42
print(8 / 2)       # 4.0
print(2 ** 3)      # 8
print((2 + 3) * 4) # 20

Desatinné čísla a zápis 0.1 + 0.1 + 0.1

Desatinné čísla v Pythone píšeme s bodkou. Správny zápis je 0.1 + 0.1 + 0.1 (nie 01.). Typ float ukladá čísla v binárnom tvare, preto výsledok súčtu nemusí byť vnútorne presne desatinná 0.3. Pri zobrazovaní ho možno zaokrúhliť:

sucet = 0.1 + 0.1 + 0.1
print(sucet)       # približne 0.30000000000000004
print(f"{sucet:.1f}")  # 0.3

6. Pygame (keď ho budeme potrebovať)

Pygame je Python knižnica, nie VS Code rozšírenie. Po výbere Python 3.12 interpreteru otvori terminál a nainštaluj ho do toho istého interpreteru:

py -3.12 -m pip install pygame
py -3.12 -m pygame.examples.aliens

Prvý príkaz nainštaluje balík, druhý spustí príklad Pygame. Ak inštalácia zlyhá, skopíruj chybové hlásenie a obráť sa na vyučujúceho; neinštaluj náhodné balíky z neznámych stránok.

Otvoriť online Python editor Programiz na rýchle skúšanie krátkych ukážok. Online editor nevyužíva Python nainštalovaný v počítači a nemusí vedieť spúšťať Pygame; Pygame skúšaj lokálne vo VS Code.

Príprava pre učiteľa: Portable VS Code nastavuje žiak alebo správca v zapisovateľnom priečinku C:\Progs\VSC. Inštalátor Pythonu potrebuje stiahnuť a nainštalovať osobitne. Pri pomalom školskom pripojení je vhodné vopred overiť prístup na stránky Microsoftu, Python.org a Marketplace a pripraviť schválené inštalačné súbory. Časový plán je orientačný a predpokladá dostupné počítače a pripojenie.

Použité zdroje

  • Microsoft: VS Code Portable Mode – nastavenie ZIP verzie a manuálna aktualizácia.
  • Microsoft: stiahnutie Visual Studio Code a inštalácia na Windows.
  • Python.org: vydanie Python 3.12.10 a Windows inštalátory; Python.org: Python 3.12.15 (bezpečnostné vydanie, zdrojové súbory).
  • Microsoft: Python vo VS Code – úvodný návod.
  • Microsoft Python extension, Pylance, Python Debugger a Jupyter.
  • Pygame na PyPI – oficiálne pokyny na inštaláciu a testovacie príklady.
