Win32 API Desktop Vývoj

Tvorba natívnych desktopových okenných aplikácií pre operačný systém Microsoft Windows.

🖥️ Náplň kurzu

  • Architektúra riadená udalosťami (Event-Driven Architecture).
  • Vstupný bod wWinMain, registrácia triedy okna a Message Loop.
  • Spracovanie správ v procedúre okna WndProc.
  • Vkladanie ovládacích prvkov (tlačidlá, štítky, vstupné polia).
  • GDI kreslenie a správa systémových zdrojov.
