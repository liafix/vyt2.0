Čo je triedenie?

Triedenie je usporiadanie prvkov do poradia (vzostupne/zostupne). Využíva sa pri vyhľadávaní, tabuľkách, výpisoch z databáz, spracovaní nameraných hodnôt zo senzorov.

Bubble sort (bublinkové triedenie)

Porovnávame susedné dvojice. Ak sú v zlom poradí, vymeníme ich. Po každom prechode je najväčší prvok z ešte neusporiadanej časti na konci. Ak počas celého prechodu nenastane výmena, zoznam je už zoradený a môžeme skončiť.

Pseudokód 
pre i od 0 po n-2:
    vymenene = nepravda
    pre j od 0 po n-i-2:
        ak a[j] > a[j+1]:
            vymeň a[j] a a[j+1]
            vymenene = pravda
    ak vymenene je nepravda:
        skonči
Python 
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        vymenene = False
        for j in range(n - i - 1):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                vymenene = True
        if not vymenene:
            break
    return a

cisla = [5, 3, 8, 1, 9, 2]
print(bubble_sort(cisla))  # [1, 2, 3, 5, 8, 9]

Selection sort (triedenie výberom)

V neusporiadanej časti nájdeme najmenší prvok a vymeníme ho s prvým z tejto časti. Neusporiadaná časť sa každým krokom skracuje.

Pseudokód 
pre i od 0 po n-2:
    minimum = i
    pre j od i+1 po n-1:
        ak a[j] < a[minimum]:
            minimum = j
    vymeň a[i] a a[minimum]
Python 
def selection_sort(a):
    n = len(a)
    for i in range(n - 1):
        min_i = i
        for j in range(i + 1, n):
            if a[j] < a[min_i]:
                min_i = j
        a[i], a[min_i] = a[min_i], a[i]
    return a

Insertion sort (triedenie vkladaním)

Postupne berieme ďalší prvok a vkladáme ho na správne miesto v už zoradenej ľavej časti zoznamu. Podobá sa zoraďovaniu kariet v ruke. Pri takmer zoradenom zozname môže byť praktický, v najhoršom prípade však vykoná približne n·(n−1)/2 porovnaní.

def insertion_sort(a):
    for i in range(1, len(a)):
        prvok = a[i]
        j = i - 1
        while j >= 0 and a[j] > prvok:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = prvok
    return a

print(insertion_sort([5, 3, 8, 1, 9, 2]))  # [1, 2, 3, 5, 8, 9]

Úlohy

  1. Ručne zapíš stav zoznamu [4, 2, 7, 1] po každom prechode bubble sortu.
  2. Uprav bubble_sort tak, aby triedil zostupne.
  3. Pridaj do funkcie počítadlo porovnaní a otestuj ho na 10 náhodných číslach (random.randint).
  4. Zorad zoznam nameraných teplôt a bezpečne vypíš najnižšiu, najvyššiu a medián (uvažuj párny aj nepárny počet meraní).
  5. ★ Zoraď zoznam dvojíc (meno, vek) podľa veku. Čo sa stane pri rovnakom veku?
Riešenia 1) [2,4,1,7] → [2,1,4,7] → [1,2,4,7]
2) Zmeň porovnanie na a[j] < a[j + 1].
3) Pred cyklami nastav pocet = 0; vo vnútornom cykle pred podmienkou zvýš pocet += 1. Každé vykonanie podmienky je jedno porovnanie.
4) t = sorted(teploty); ak je t prázdne, medián ani krajné hodnoty nemajú výsledok. Inak nastav n = len(t); medián je t[n // 2] pri nepárnom počte a (t[n // 2 - 1] + t[n // 2]) / 2 pri párnom počte.
5) sorted(data, key=lambda x: x[1]). Pythonovo triedenie je stabilné, takže dvojice s rovnakým vekom zachovajú pôvodné poradie.
Diferenciácia a hodnotenie Opora: použi zoznam štyroch čísel a kartičky; žiak označí porovnávané susedné dvojice. Rozšírenie: nech žiaci odhadnú počet porovnaní pre n prvkov a porovnajú to s počítadlom v programe. Hodnoť správne trasovanie, vysvetlenie podmienky výmeny a funkčné testy.

Zhrnutie pre žiakov

Triedenie usporiada prvky podľa pravidla. Bubble sort mení susedov, selection sort hľadá minimum. Oba majú dva vnorené cykly, preto sú pomalé pri veľkých zoznamoch. V praxi používame sorted().
