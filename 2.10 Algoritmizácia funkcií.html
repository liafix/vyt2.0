2.10 Algoritmizácia funkcií

2 × 45 min funkcie · podprogramy · Python

Funkcia je pomenovaná časť programu, ktorá rieši jednu úlohu. Naučíš sa rozdeliť problém na menšie kroky, odovzdať funkcii vstupy a podľa potreby získať výsledok.

Čo je funkcia a prečo ju používame?

Funkcia (podprogram) je pomenovaný blok kódu, ktorý vykonáva určitú úlohu. Po definovaní ho môžeme zavolať z rôznych miest programu a s rôznymi vstupmi.

  • Menej opakovania: rovnaký postup zapíšeme raz.
  • Prehľadnejší program: názov funkcie pomáha pochopiť, čo sa deje.
  • Jednoduchšie testovanie a opravy: menšiu časť vieme overiť samostatne.
  • Rozdelenie práce: väčší problém rozdelíme medzi menšie funkcie.

Vytvorenie a volanie funkcie

V Pythone sa funkcia začína kľúčovým slovom def. Telo funkcie je odsadené. Funkcia sa vykoná až vtedy, keď ju zavoláme jej menom.

def sucet(a, b):
    return a + b

vysledok = sucet(5, 7)
print(vysledok)  # 12

Parametre, argumenty a návratová hodnota

PojemVýznamPríklad
ParameterMeno vstupnej hodnoty v definícii funkcie.a a b v def sucet(a, b)
ArgumentKonkrétna hodnota odovzdaná pri volaní.5 a 7 v sucet(5, 7)
Návratová hodnotaVýsledok odovzdaný späť príkazom return.a + b

Funkcia môže aj iba vykonať činnosť, napríklad vypísať pozdrav. Ak nemá príkaz return, vráti hodnotu None.

def pozdrav():
    print("Ahoj, Python!")

def obvod_stvorca(strana):
    return 4 * strana

pozdrav()
print(obvod_stvorca(5))  # 20
Zapamätaj si: print() zobrazuje informáciu. return odovzdáva hodnotu ďalej, aby sa dala uložiť, porovnať alebo použiť vo výpočte.

Rovnaká funkcia, rôzne vstupy

def obvod_obdlznika(a, b):
    return 2 * (a + b)

print(obvod_obdlznika(4, 5))  # 18
print(obvod_obdlznika(3, 7))  # 20

Funkciu nemusíme kopírovať. Pri každom volaní jej odovzdáme iné argumenty.

Rozklad úlohy na podprogramy

Úloha: vypočítať priemer troch čísel. Samostatná funkcia môže riešiť výpočet, zatiaľ čo hlavný program sa postará o zadanie údajov a zobrazenie výsledku.

def priemer(a, b, c):
    return (a + b + c) / 3

priemer_hodnot = priemer(2, 4, 6)
print("Priemer:", priemer_hodnot)  # Priemer: 4.0

2. hodina – rozsah, predvolené hodnoty a typy

Plán 2. hodiny Rozsah premenných ukážte spustením krátkeho príkladu a predikciou výstupu. Pri kalkulačke žiadajte testy pre nulu, záporné hodnoty aj delenie nulou. Pri predvolených parametroch vysvetlite, prečo parameter s predvolenou hodnotou musí byť za povinnými parametrami.

Lokálne a globálne premenné

Lokálna premenná vznikne vo funkcii a používa sa v nej. Globálna premenná je vytvorená mimo funkcií. Ak funkcia len číta hodnotu globálnej premennej, netreba ju označovať ako global; vo všeobecnosti je však vhodnejšie odovzdať vstup cez parameter a výsledok vrátiť.

x = 10  # globálna premenná

def test():
    x = 5  # lokálna premenná; nezmení globálne x
    print("Vo funkcii:", x)

test()
print("Mimo funkcie:", x)
# Vo funkcii: 5
# Mimo funkcie: 10

Predvolené (prednastavené) parametre

Predvolená hodnota sa použije, keď argument pri volaní vynecháme. Povinné parametre zapisujeme pred parametrami s predvolenou hodnotou.

def pozdrav(meno="žiak"):
    print("Ahoj,", meno)

pozdrav()          # Ahoj, žiak
pozdrav("Peter")   # Ahoj, Peter

def mocnina(x, n=2):
    return x ** n

print(mocnina(3))     # 9
print(mocnina(2, 5))  # 32

Typové anotácie (type hints)

Typové anotácie dokumentujú očakávané vstupy a výsledok. Python ich pri bežnom spustení automaticky nevynucuje; kontrolovať ich môžu editor alebo samostatné nástroje.

def sucet(a: int, b: int) -> int:
    return a + b

def priemer(a: float, b: float, c: float) -> float:
    return (a + b + c) / 3

print(sucet(5, 7))  # 12

Ukážkový program: jednoduchá kalkulačka

Každá funkcia vykonáva jednu pomenovanú operáciu. Pri delení ošetríme zakázaný vstup.

def sucet(a: float, b: float) -> float:
    return a + b

def rozdiel(a: float, b: float) -> float:
    return a - b

def sucin(a: float, b: float) -> float:
    return a * b

def podiel(a: float, b: float) -> float:
    if b == 0:
        raise ValueError("Nulou nemožno deliť.")
    return a / b

x = float(input("Zadaj prvé číslo: "))
y = float(input("Zadaj druhé číslo: "))

print("Súčet:", sucet(x, y))
print("Rozdiel:", rozdiel(x, y))
print("Súčin:", sucin(x, y))
try:
    print("Podiel:", podiel(x, y))
except ValueError as chyba:
    print(chyba)

Postup algoritmizácie s funkciami

  1. Pomenuj problém a urč, aký výsledok má program vytvoriť.
  2. Rozdeľ problém na menšie úlohy; každej priraď jasnú zodpovednosť.
  3. Pri každej funkcii urč vstupy (parametre) a výstup (návratovú hodnotu), ak ju potrebuje.
  4. Napíš a otestuj jednotlivé funkcie samostatne.
  5. Spoj ich do hlavného programu a otestuj aj celý postup.

Precvičovanie

Úloha 1 – obsah obdĺžnika: Vytvor funkciu obsah_obdlznika(a, b), ktorá vráti obsah. Otestuj ju pre strany 4 a 5; očakávaný výsledok je 20.
Úloha 2 – párne číslo: Vytvor funkciu je_parne(n), ktorá vráti True, ak je celé číslo párne, inak False. Otestuj kladné aj záporné číslo a nulu.
Úloha 3 – pozdrav s predvolenou hodnotou: Napíš pozdrav(meno="žiak"), ktorá vráti text pozdravu. Vyskúšaj volanie bez argumentu aj s menom.
Úloha 4 – kalkulačka: Doplň funkcie pre súčet, rozdiel, súčin a podiel. Otestuj bežné čísla, záporné číslo a delenie nulou.
Riešenia na kontrolu 
def obsah_obdlznika(a, b):
    return a * b

def je_parne(n):
    return n % 2 == 0

def pozdrav(meno="žiak"):
    return f"Ahoj, {meno}!"
Pri obsahu obdĺžnika obsah_obdlznika(4, 5) vráti 20. Funkcia je_parne vráti pravdivostnú hodnotu. Pri delení nulou vhodne oznám chybu, napríklad výnimkou ValueError.
