2.5 Algoritmizácia podmienky

1 × 45 min Teória a Python

Ciele hodiny

Žiak vysvetlí, že podmienka vyhodnocuje logický výraz na True alebo False, použije porovnávacie operátory, zapíše jednoduché vetvenie v Pythone pomocou if a else, vysvetlí obe vetvy a otestuje hraničné aj bežné vstupy.

1. Čo je podmienka?

Podmienka umožňuje algoritmu rozhodnúť sa, čo vykonať ďalej. Najprv sa vyhodnotí logický výraz. Ak je výsledkom True (pravda), vykoná sa jedna vetva; ak je False (nepravda), vykoná sa druhá vetva alebo sa blok preskočí.

Bežný príklad: Ak prší, vezmi si dáždnik, inak choď bez neho. Otázka „Prší?“ má dve možné odpovede, ktoré určia ďalší krok.

2. Logické výrazy a porovnania

Porovnávacie operátory porovnávajú hodnoty a vracajú True alebo False. V Pythone ich zapisujeme takto:

OperátorVýznamPríkladVýsledok
==rovná sa5 == 5True
!=nerovná sa5 != 3True
>je väčšie ako4 > 7False
<je menšie ako2 < 8True
>=je väčšie alebo rovné18 >= 18True
<=je menšie alebo rovné0 <= 0True

Operátor = priraďuje hodnotu do premennej; == porovnáva dve hodnoty. Zápis vek = 18 zmení premennú, kým vek == 18 je otázka s výsledkom pravda/nepravda.

3. Jednoduché vetvenie: if a else

V Pythone slovo if znamená „ak“ a else „inak“. Dvojbodka ukončuje hlavičku podmienky a odsadené riadky tvoria blok príkazov:

podmienka = True

if podmienka:
    print("Podmienka je splnená.")
else:
    print("Podmienka nie je splnená.")
  • Dvojbodka : za podmienkou je povinná.
  • Príkazy patriace do vetvy sa odsádzajú, zvyčajne štyrmi medzerami.
  • Obe vetvy môžu obsahovať jeden alebo viac príkazov.
  • Pri if/else sa vykoná práve jedna z vetiev.

4. Príklad: párne alebo nepárne číslo

Operátor % vypočíta zvyšok po delení. Ak je zvyšok pri delení dvoma rovný nule, číslo je párne.

cislo = int(input("Zadaj celé číslo: "))

if cislo % 2 == 0:
    print("Číslo je párne.")
else:
    print("Číslo je nepárne.")

Pri vstupe 8 je výraz cislo % 2 == 0 pravdivý a vypíše sa „párne“. Pri vstupe 7 je nepravdivý a vykoná sa vetva else.

5. Vetvenie vo vývojovom diagrame

Kosoštvorec predstavuje rozhodnutie. Má jeden vstup a vetvy pre výsledky „áno“ a „nie“. Po vykonaní príslušnej činnosti sa cesty môžu opäť spojiť a pokračovať spoločným postupom.

6. Hraničné hodnoty a úplnosť

Pri návrhu podmienky si over, či pokrýva všetky možnosti vrátane hranice. Ak chceme rozlíšiť záporné číslo a číslo, ktoré je nula alebo väčšie, podmienka n >= 0 pokrýva aj nulu. Pri n > 0 by nula patrila do druhej vetvy.

Trasovanie príkladu n >= 0:
  • n = 5 → True → nezáporné.
  • n = 0 → True → nezáporné.
  • n = -2 → False → záporné.

7. Viac možností: elif

Ak treba rozlíšiť viac než dva prípady, môžeme pridať jednu alebo viac vetiev elif („inak, ak“). Python skúša podmienky zhora nadol a vykoná iba prvú pravdivú vetvu. Ak nie je pravdivá žiadna a je uvedené else, vykoná sa posledná vetva.

teplota = float(input("Zadaj teplotu: "))

if teplota < 0:
    print("Mrzne.")
elif teplota == 0:
    print("Teplota je presne nula.")
else:
    print("Teplota je nad nulou.")

Vetvy elif tu iba predstavujeme; zložitejšie, vnorené rozhodovanie a návrh úplného stromu možností precvičíme v téme 2.6 Algoritmizácia vnorenej podmienky.

8. Časté chyby

  • Zámena = a ==: na porovnanie použi ==, nie priradenie.
  • Chýbajúca dvojbodka: za if, elif a else patrí :.
  • Nesprávne odsadenie: všetky príkazy jedného bloku musia byť odsadené rovnako; štandardne štyrmi medzerami.
  • Neúplné prípady: otestuj aj nulu a hodnoty presne na hranici.
  • Zbytočne zložité podmienky: najprv pomenuj, čo presne testuješ; zložité rozhodovanie rozdeľ na zrozumiteľné kroky.
  • Porovnávanie desatinných čísel na presnú rovnosť: výsledky výpočtov s float môžu byť nepresné; pri takých úlohách použi vhodnú toleranciu.

9. Precvičenie

  1. Napíš program, ktorý načíta vek a vypíše, či je používateľ plnoletý (hranica 18 rokov).
  2. Načítaj celé číslo a rozhodni, či je kladné alebo nekladné. Otestuj aj nulu.
  3. Vysvetli, ktorá vetva sa vykoná pri body = 50 a podmienke body >= 50.
  4. Uprav príklad s teplotou tak, aby vypísal, či je teplota najviac 20 °C.
  5. Ku každej vlastnej podmienke zapíš aspoň jeden vstup, pre ktorý je pravdivá, a jeden, pre ktorý je nepravdivá.
Poznámka pre učiteľa: Vysvetlite, že podmienka je výraz s výsledkom typu bool, nie príkaz na vykonanie. V príklade s nulou nechajte žiakov predpovedať výsledok ešte pred spustením. V 45 minútach stačí precvičiť jednu vetvu if, úplnú dvojvetvovú voľbu if/else a stručne ukázať elif; zložité vnorené podmienky ponechajte na nasledujúcu tému.
