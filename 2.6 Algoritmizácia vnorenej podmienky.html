2.6 Algoritmizácia vnorenej podmienky

Ciele hodiny

Žiak vysvetlí, čo je vnorená podmienka a kedy je druhé rozhodnutie závislé od prvého, správne odsádza bloky if/elif/else, trasuje vnorený program a rozhodne, či je vhodnejšie vnorenie alebo spojenie podmienok pomocou and.

1. Čo je vnorená podmienka?

Vnorená podmienka je podmienka zapísaná vo vnútri bloku inej podmienky. Program najprv vyhodnotí vonkajšiu podmienku. K vnorenému rozhodnutiu sa dostane iba vtedy, keď vykoná príslušný vonkajší blok. Vnorenie preto vyjadruje hierarchiu: najprv over A, a len ak A platí, rozhoduj podľa B.

Napríklad pri kontrole prístupu sa najprv overí, či je používateľ prihlásený. Až prihlásenému používateľovi má zmysel kontrolovať, či má oprávnenie na konkrétnu činnosť. Ak prvá podmienka neplatí, druhý test sa vôbec nevykoná.

2. Syntax a odsadenie

Každá úroveň vnorenia pridáva ďalšie odsadenie. V Pythone odsadenie nie je len vizuálne formátovanie – určuje, ktoré príkazy patria do ktorého bloku.

if vonkajsia_podmienka:
    # Vonkajší blok: 4 medzery
    if vnorena_podmienka:
        # Vnorený blok: 8 medzier
        print("Obe podmienky platia.")
    else:
        # Toto else patrí vnorenému if
        print("Platí iba vonkajšia podmienka.")
else:
    # Toto else patrí vonkajšiemu if
    print("Vonkajšia podmienka neplatí.")
  • Vonkajší blok sa odsádza zvyčajne štyrmi medzerami a blok vo vnútri neho ďalšími štyrmi.
  • else alebo elif musí byť zarovnané s príslušným if.
  • else patrí k najbližšiemu predchádzajúcemu if na rovnakej úrovni odsadenia, ku ktorému ešte nebolo priradené.
  • Editor kódu pomáha odsadením a zvýraznením blokov, ale logiku vetiev musí skontrolovať programátor.

3. Príklad: výsledok testu a dochádzka

V tomto príklade známky sú v rozsahu 1–5. Najprv sa rozlíši známka. Dochádzka sa kontroluje iba pri známke 1 alebo 2.

# Vstupy príkladu
znamka = 2
dochadzka = 85  # percentá

if znamka <= 2:
    # Sem patrí známka 1 alebo 2
    if dochadzka >= 80:
        print("Študent dostane pochvalu.")
    else:
        print("Študent má dobrú známku, ale slabú dochádzku.")
elif znamka == 3:
    print("Študent prešiel s priemerným výsledkom.")
else:
    # Pri predpoklade známok 1 až 5 sem patria 4 a 5
    print("Študent neprešiel.")

Pri hodnotách znamka = 2 a dochadzka = 85 platí vonkajšie porovnanie znamka <= 2. Program potom vyhodnotí vnorené dochadzka >= 80, ktoré je tiež pravdivé, a vypíše pochvalu. Ak by dochádzka bola 70 %, vykonala by sa vnorená vetva else. Pre známku 3 sa vnorený test vôbec nevykonáva.

Dôležitý predpoklad: Záverečné else v tomto príklade znamená známky 4 alebo 5 len preto, že predpokladáme platný rozsah 1–5. Ak používateľ zadáva údaje, treba osobitne overiť, že známka aj percentá dochádzky sú v povolenom rozsahu.

4. Ako čítať strom rozhodnutí

Vnorené podmienky možno čítať ako strom: každá odpoveď rozvetví postup a ďalší test sa nachádza len v tej vetve, v ktorej je potrebný. Pri návrhu si vypíš možné výsledky, označ, ktoré podmienky sa týkajú každej vetvy, a skontroluj, že všetky prípady majú jasný koniec.

5. Trasovanie programu

Trasovanie znamená prejsť kód príkaz po príkaze a zaznamenať, ktoré podmienky sú pravdivé a ktoré riadky sa vykonajú. Pozor: else patrí k vonkajšiemu alebo vnorenému if podľa svojho odsadenia.

vek = 16
ma_skusenosti = True

if vek >= 18:
    print("1")
    if ma_skusenosti:
        print("2")
else:
    print("3")
    if ma_skusenosti:
        print("4")

Priebeh: vek >= 18 je nepravdivé, preto sa vykoná jeho vonkajšie else. Vypíše sa 3. V tomto bloku je ma_skusenosti pravdivé, preto sa vypíše aj 4. Správna odpoveď je c) 3 potom 4.

6. Kedy vnoriť a kedy použiť and?

Vnorenie je vhodné, keď druhá podmienka závisí od prvej, keď treba podať odlišnú spätnú väzbu pre jednotlivé dôvody alebo keď sa po prvej kontrole vykonáva väčší samostatný blok. Ak majú obe podmienky viesť k rovnakej činnosti, môžu byť prehľadnejšie spojené operátorom and.

vek = 18
ma_skusenosti = True

if vek >= 18 and ma_skusenosti:
    print("Osoba spĺňa obe kritériá.")
else:
    print("Osoba nespĺňa aspoň jedno kritérium.")

V Pythone je operátor „a zároveň“ zapísaný malými písmenami and. Zápis vek = 18 je priradenie, preto ním nemožno testovať podmienku; na porovnanie použijeme napríklad vek >= 18 alebo vek == 18. Pri použití and Python vyhodnocuje výrazy zľava doprava a môže skončiť hneď, keď už pozná výsledok celého výrazu (skrátené vyhodnocovanie).

Pomôcka pre výber:
  • if A: a až v jeho bloku if B: – B testujeme len v prípade, že A platí, prípadne potrebujeme rozdielne kroky.
  • if A and B: – jediný blok sa vykoná iba vtedy, keď platia obe podmienky.
  • Pri vstupnej validácii dbaj na poradie: kratší alebo bezpečný test možno vykonať pred testom, ktorý predpokladá platný vstup.

7. Časté chyby

  • Nesprávne odsadenie: riadok sa omylom zaradí do inej vetvy; skontroluj úroveň medzier a poradie blokov.
  • Nejasné priradenie else: else patrí k najbližšiemu nezodpovedanému if s rovnakým odsadením.
  • Zbytočne hlboké vnáranie: príliš veľa úrovní sťažuje čítanie; zváž skoršie ukončenie vetvy, funkcie alebo zjednodušenie logiky.
  • Nedefinovaná premenná: premenná použitá vo vnútornom teste musí dostať hodnotu ešte pred tým, než sa k testu program dostane.
  • Neúplné prípady: over, čo sa stane pri nesplnení prvej podmienky, pri hraničných hodnotách aj pri neplatnom vstupe.
  • Neplatný zápis porovnania: nepíš vek = 18 ako podmienku; priraďovanie a porovnávanie sú odlišné operácie.

8. Precvičenie

  1. Uveď, ku ktorému if patrí každé else v príklade s vekom a vysvetli, prečo sa vypíšu 3 a 4.
  2. Uprav príklad so známkou tak, aby kontroloval dochádzku iba pri známke 1 alebo 2. Otestuj hodnoty 1, 2, 3 a 4.
  3. Navrhni vnorené rozhodnutie: najprv over, či je používateľ prihlásený, a až potom, či má oprávnenie. Každú situáciu ukonči vhodnou správou.
  4. V kalkulačke vysvetli, prečo sa kontrola deliteľa b == 0 vykonáva iba vo vetve delenia.
  5. Prepíš príklad „vek a skúsenosti“ s and na vnorené if. Porovnaj, či výsledné správy poskytujú rovnako podrobnú spätnú väzbu.
Poznámka pre učiteľa: Začnite trasovaním príkladu, kde je vek 16. Nechajte žiakov najprv určiť, ku ktorému if patrí vonkajšie else. Pri príklade so známkou zdôraznite predpoklad povoleného rozsahu 1–5. Neprehĺbte tému za dve až tri úrovne; cieľom je správne vysvetliť závislosť podmienok, odsadenie a väzbu else.
