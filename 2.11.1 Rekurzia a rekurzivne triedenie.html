2.11.1 Rekurzia a rekurzívne triedenie

2 × 45 min (návrh) funkcie · rozklad problému · Python

Úvod: čo znamená rekurzia?

V tejto téme sa naučíš, ako môže funkcia vyriešiť úlohu tak, že zavolá samu seba s menším problémom. Rekurziu si najprv ukážeme na jednoduchom odpočítavaní, potom na faktoriáli a napokon na algoritmoch, ktoré triedia zoznamy rozdelením na menšie časti.

Pri každom príklade hľadaj dve dôležité veci: kde sa volanie zastaví a ako sa vstup pri ďalšom volaní zmenší. Bez podmienky zastavenia by funkcia pokračovala, až kým by Python nenahlásil chybu.

Čo je rekurzia?

Rekurzia je spôsob riešenia úlohy, pri ktorom funkcia volá samu seba s menším alebo jednoduchším vstupom. Volania pokračujú, kým nenarazia na základný prípad, ktorý už ďalšie volanie nepotrebuje. Každé rekurzívne volanie musí smerovať k tomuto prípadu.

Zapamätaj si dva diely:
  • Základný prípad – kedy sa funkcia zastaví.
  • Rekurzívny krok – ako sa problém zmenší a funkcia zavolá samu seba.

Prvý príklad: odpočítavanie

def odpocitaj(n):
    if n == 0:                 # základný prípad
        print("Štart!")
        return
    print(n)
    odpocitaj(n - 1)            # menší problém

odpocitaj(3)

Výpis je 3, 2, 1, Štart!. Pri volaní odpocitaj(0) sa funkcia zastaví. Keby sme zmenšovanie vstupu vynechali, funkcia by sa nezastavila správne.

Faktoriál a návrat zo zásobníka

Faktoriál čísla n je súčin čísel od 1 po n. Platí 0! = 1 a pre kladné n platí n! = n · (n−1)!.

def faktorial(n):
    if n < 0:
        raise ValueError("Faktoriál je definovaný len pre n >= 0")
    if n == 0:                  # základný prípad
        return 1
    return n * faktorial(n - 1)

print(faktorial(4))  # 24

Pri faktorial(4) sa najprv volá faktorial(3), potom faktorial(2), faktorial(1) a napokon faktorial(0). Výsledky sa dopočítajú pri návrate: 1 → 1 → 2 → 6 → 24.

Časté chyby Chýbajúci základný prípad alebo vstup, ktorý sa k nemu nepribližuje, spôsobí priveľa volaní a nakoniec RecursionError. Vysvetli, že volania čakajú na zásobníku na výsledok hlbšieho volania. Python má limit hĺbky rekurzie; nezvyšuj ho ako náhradu za správny základný prípad.

Rekurzívne triedenie

Niektoré algoritmy rozdelia zoznam na menšie časti, tie vyriešia rekurzívne a následne spoja výsledky. Takýto prístup sa nazýva rozdeľ a panuj.

Merge sort (triedenie zlučovaním)

Zoznam rozdeľujeme na polovice až po časti s najviac jedným prvkom. Tie sú už zoradené. Potom zoradené polovice postupne zlúčime. Základný prípad je zoznam s dĺžkou 0 alebo 1.

def merge(left, right):
    vysledok = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            vysledok.append(left[i])
            i += 1
        else:
            vysledok.append(right[j])
            j += 1
    return vysledok + left[i:] + right[j:]

def merge_sort(a):
    if len(a) <= 1:             # základný prípad
        return a
    stred = len(a) // 2
    lava = merge_sort(a[:stred])
    prava = merge_sort(a[stred:])
    return merge(lava, prava)

print(merge_sort([5, 3, 8, 1, 9, 2]))  # [1, 2, 3, 5, 8, 9]

Časová zložitosť je približne O(n log n). Táto jednoduchá implementácia vytvára pomocné zoznamy, preto používa dodatočnú pamäť.

Quick sort (rýchle triedenie)

Vyberieme pivot a rozdelíme prvky na menšie, rovnaké a väčšie. Potom rekurzívne zoradíme menšiu a väčšiu skupinu. Základný prípad je skupina s najviac jedným prvkom.

def quick_sort(a):
    if len(a) <= 1:             # základný prípad
        return a
    pivot = a[len(a) // 2]
    mensie = [x for x in a if x < pivot]
    rovnake = [x for x in a if x == pivot]
    vacsie = [x for x in a if x > pivot]
    return quick_sort(mensie) + rovnake + quick_sort(vacsie)

print(quick_sort([5, 3, 8, 1, 9, 2]))  # [1, 2, 3, 5, 8, 9]

Ide o zjednodušenú verziu, ktorá vytvára nové zoznamy. Quick sort má pri vhodnom rozdelení priemernú zložitosť O(n log n); pri veľmi nevyváženom delení môže mať O(n²).

Úlohy

  1. Napíš funkciu sucet_do(n) pre nezáporné celé n, ktorá rekurzívne vráti súčet čísel od 1 po n. Urči základný prípad.
  2. Vypíš poradie volaní aj návratových hodnôt pre faktorial(3).
  3. Vysvetli, prečo sa merge_sort([]) a merge_sort([7]) zastavia.
  4. Uprav quick_sort a otestuj ho na zozname s opakovanými číslami.
  5. ★ Porovnaj počet delení pri merge_sort a quick_sort. Prečo môže voľba pivota ovplyvniť quick sort?
Náčrt riešení 1) Základný prípad n == 0 vráti 0; inak vráť n + sucet_do(n - 1).
2) Volania: faktorial(3) → 3 · faktorial(2) → 3 · 2 · faktorial(1) → 3 · 2 · 1 · faktorial(0); návraty: 1, 1, 2, 6.
3) Dĺžka zoznamu je najviac 1, takže sa vykoná základný prípad bez ďalšieho volania.
4) Funkcia rozdeľuje rovnaké hodnoty do zoznamu rovnake; príklad [3, 1, 3, 2] vráti [1, 2, 3, 3].
5) Merge sort rozdeľuje na polovice pravidelne; quick sort závisí od rozdelenia prvkov okolo pivota. Veľmi nevyvážené časti znamenajú viac úrovní volaní.

Zhrnutie

Rekurzívna funkcia potrebuje správny základný prípad a krok, ktorý ju k nemu približuje. Volania sa ukladajú, kým sa nedosiahne základný prípad, a potom sa výsledky vracajú späť. Merge sort a quick sort používajú rekurziu na riešenie menších častí zoznamu.
