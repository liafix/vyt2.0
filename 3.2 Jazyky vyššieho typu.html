1. Vyššie programovacie jazyky

Vyšší jazyk umožňuje zapisovať riešenia pomocou abstraktnejších konštrukcií, než sú jednotlivé inštrukcie procesora. Programátor tak pracuje napríklad s premennými, funkciami, kolekciami a triedami. Zdrojový kód sa vykoná prostredníctvom prekladača alebo runtime prostredia; konkrétny postup závisí od jazyka a implementácie.

Python je vysokoúrovňový, dynamicky typovaný a viacparadigmový jazyk. Podporuje procedurálny, objektovo orientovaný i funkcionálny štýl. V tejto téme sa sústredíme na OOP – spôsob organizovania programu okolo objektov, ich stavu a správania.

2. Trieda a objekt

Trieda je používateľom definovaný typ a opis spoločných atribútov a metód. Objekt (inštancia) je konkrétna hodnota vytvorená podľa triedy. Analógia s plánom domu pomáha predstave: plán je trieda, jednotlivé postavené domy sú objekty; každý môže mať vlastné hodnoty niektorých vlastností.

class GameObject:
    def __init__(self, name, health, attack):
        self.name = name
        self.health = health
        self.attack = attack

    def take_damage(self, amount):
        self.health = max(0, self.health - amount)

    def is_alive(self):
        return self.health > 0
  • class GameObject: definuje novú triedu; názov triedy sa bežne píše v štýle PascalCase.
  • __init__ je inicializačná metóda, ktorú Python zavolá pri vytváraní novej inštancie. Nejde o metódu, ktorá sama vytvára objekt.
  • self odkazuje na konkrétnu inštanciu. Pri volaní objekt.is_alive() Python túto inštanciu odovzdá metóde ako prvý argument.
  • name, health a attack sú atribúty inštancie, teda údaje patriace konkrétnemu objektu.
  • take_damage a is_alive sú metódy, teda správanie definované v triede.

3. Vytvorenie objektov a ich vlastný stav

player1 = GameObject("Player 1", 100, 20)
player2 = GameObject("Player 2", 120, 15)
enemy = GameObject("Enemy", 80, 10)

print(player1.name, player1.health)  # Player 1 100
print(player2.name, player2.health)  # Player 2 120

Všetky tri objekty vznikli z rovnakej triedy a majú rovnaké pomenované atribúty a metódy. Ich hodnoty sú však nezávislé: poškodenie jedného objektu samo osebe nemení zdravie ostatných.

4. Interakcia medzi objektmi

Objekty môžu spolupracovať tak, že jedna metóda dostane druhý objekt ako argument a vyvolá na ňom jeho metódu:

print("--- Začiatok súboja ---")
enemy.take_damage(player1.attack)
player1.take_damage(enemy.attack)
player2.take_damage(enemy.attack)

print("\n--- Stav po útokoch ---")
print(f"{player1.name} je živý: {player1.is_alive()}")
print(f"{player2.name} je živý: {player2.is_alive()}")
print(f"{enemy.name} je živý: {enemy.is_alive()}")

Nepriateľ utrpí 20 bodov poškodenia, hráč 1 utrpí 10 a hráč 2 tiež 10. Metóda take_damage zníži zdravie, ale nie pod nulu; metóda is_alive vráti logickú hodnotu.

5. Dedičnosť

Dedičnosť umožňuje definovať novú triedu na základe existujúcej. Potomok zdedí jej verejné správanie, môže pridať svoje metódy a prípadne niektoré zdedené metódy prepísať. Používame ju tam, kde medzi typmi existuje zmysluplný vzťah „je druhom“.

class Player(GameObject):
    def heal(self, amount):
        self.health += amount


class Enemy(GameObject):
    def enraged_attack(self, target):
        damage = self.attack * 2
        target.take_damage(damage)
        print(f"{self.name} zaútočil na {target.name} za {damage} bodov.")


player = Player("Hrdina", 100, 20)
enemy = Enemy("Ork", 80, 10)
enemy.enraged_attack(player)
player.heal(15)
print(player.health)  # 95 po útoku a následnom liečení

Player a Enemy zdedia inicializáciu aj metódy triedy GameObject a doplnia vlastné správanie. V reálnom programe navrhni pravidlá, napríklad maximálne zdravie, aby liečenie nemohlo viesť k neplatnému stavu.

6. Viditeľnosť atribútov v Pythone

Python nepoužíva kľúčové slová public, protected a private ako striktný systém prístupových práv v niektorých iných jazykoch. Používa predovšetkým pomenovaciu konvenciu:

ZápisKonvencia a význam
self.nameVerejné rozhranie; používa sa bežne aj zvonka objektu.
self._energyJeden podčiarkovník označuje interný alebo „protected“ prvok podľa konvencie. Prístup je technicky možný, no používatelia triedy by s ním nemali počítať ako s verejným rozhraním.
self.__secretDva úvodné podčiarkovníky spúšťajú name mangling: názov sa zmení napríklad na _Hero__secret. Pomáha to predísť kolíziám názvov v podtriedach, ale nejde o skutočné utajenie ani nepriestupnú ochranu.
class Hero:
    def __init__(self, name):
        self.name = name
        self._energy = 100
        self.__secret_code = 123

    def show_status(self):
        print(f"{self.name}: energia {self._energy}")


hero = Hero("Arthas")
hero.show_status()
print(hero.name)       # verejný atribút
print(hero._energy)    # možné, ale ide o interný detail
# hero.__secret_code  # tento názov na inštancii nie je definovaný

Pre väčšinu školských tried stačí používať verejné atribúty a interné údaje označiť jedným podčiarkovníkom. Dvojité podčiarkovníky nepoužívaj ako predstierané bezpečnostné opatrenie.

7. Volanie rodičovskej triedy pomocou super()

Ak potomok definuje vlastný __init__, môže zavolať inicializáciu rodiča pomocou super() a potom pridať svoje atribúty:

class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed


dog = Dog("Luna", "ovčiak")
print(dog.name, dog.breed)

super() nie je len pevne zakódovaný názov rodiča; v dedičnej hierarchii spolupracuje s poradím MRO, aby sa implementácie mohli korektne reťaziť.

8. Prepisovanie metód

Ak potomok definuje metódu s rovnakým menom ako zdedená metóda, jeho verzia ju pri volaní na objekte potomka prekryje. Tomu sa hovorí prepisovanie (override).

class Animal:
    def speak(self):
        return "Zviera vydáva zvuk."


class Dog(Animal):
    def speak(self):
        return "Hav-hav!"


animal = Animal()
dog = Dog("Luna")
print(animal.speak())  # Zviera vydáva zvuk.
print(dog.speak())     # Hav-hav!

Rovnaké rozhranie metódy umožňuje pracovať s rôznymi potomkami bez toho, aby volajúci musel poznať detaily každej triedy. Ak chceme zachovať aj správanie rodiča, možno v prepísanej metóde použiť super().speak().

9. Viacnásobné dedenie a MRO

Trieda v Pythone môže dediť z viac než jednej rodičovskej triedy. MRO (Method Resolution Order) je poradie, v ktorom Python hľadá metódu alebo atribút v triede a jej predkoch. Python používa algoritmus C3 linearizácie; poradie možno zobraziť cez ClassName.__mro__.

class Flyable:
    def move(self):
        return "Letím!"


class Swimmable:
    def move(self):
        return "Plávam!"


class Duck(Flyable, Swimmable):
    pass


duck = Duck()
print(duck.move())  # Letím! – Flyable je v MRO pred Swimmable
print(Duck.__mro__)

Pre danú definíciu je poradie Duck → Flyable → Swimmable → object. Viacnásobné dedenie je pokročilejší nástroj; používaj ho uvážene, lebo zložité hierarchie môžu sťažiť čitateľnosť. Pri spolupracujúcich metódach treba dodržať spoločný návrh volaní super().

  3. Pridaj do triedy metódu, ktorá vráti textový opis objektu.
  4. Vytvor triedu Player odvodenú od GameObject, ktorá pridá atribút level; inicializáciu základných atribútov zavolaj cez super().
