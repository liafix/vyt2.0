Kurz Gitu

Git zaznamenáva históriu zmien v projekte. Prejdi si najprv stručný ťahák a potom lekcie z video playlistu.

Náplň kurzu

  • Čo je Git a aký je rozdiel oproti vzdialenému repozitáru (GitHub).
  • Základný cyklus: git status, git add, git commit, git log.
  • Vetvy (branching) a zlučovanie zmien (merging).
  • Riešenie merge konfliktov.
  • Súbor .gitignore na ignorovanie dočasných súborov.

Ťahák príkazov Gitu

Otvoriť úplný ťahák príkazov od autora kurzu

Skontroluj stav a históriu

git status
git log --oneline

Priprav zmeny a vytvor commit

git add nazov-suboru
git commit -m "Popis zmeny"

Vytvor a prepni sa na vetvu

git switch -c nova-vetva
git branch

Pracuj so vzdialeným repozitárom

git remote -v
git pull
git push

Nastav meno a e-mail pre commity

git config --global user.name "Tvoje meno"
git config --global user.email "ty@example.com"

Pozor: príkazy ako git reset --hard môžu natrvalo odstrániť neuložené zmeny. Používaj ich iba vtedy, keď presne vieš, čo robia.
