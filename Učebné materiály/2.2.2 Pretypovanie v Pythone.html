2.2.2 Pretypovanie v Pythone

Podtéma Teória a príklady

Ciele

  • Vysvetliť rozdiel medzi implicitným a explicitným pretypovaním.
  • Rozpoznať základné automatické konverzie v Pythone.
  • Použiť int(), float(), str() a bool().
  • Upozorniť na stratu informácií a ošetriť neplatný číselný vstup.

1. Typ a pretypovanie

Dátový typ určuje, akú hodnotu premenná predstavuje a aké operácie s ňou dávajú zmysel. Pretypovanie (konverzia typu) je prevod hodnoty z jedného typu na iný. Pri implicitnom pretypovaní prevod vykoná Python automaticky; pri explicitnom ho programátor vyžiada vo svojom kóde.

2. Implicitné pretypovanie

Pri číselnom výraze, ktorý kombinuje celé číslo int a desatinné číslo float, Python prevedie celé číslo na float, aby mohol vyhodnotiť výraz:

a = 5       # int
b = 2.0     # float
c = a + b
print(type(c), c)  # <class 'float'> 7.0

Hodnoty typu bool sa v číselnom kontexte správajú ako 0 a 1 (False a True). Je to vlastnosť Pythonu, nie však odporúčaný spôsob zápisu bežných výpočtov:

print(True + 3)  # 4

Python naopak automaticky neprevedie textové číslice na číslo. Výraz "3" + 4 vyvolá chybu TypeError; reťazec treba previesť explicitne.

3. Explicitné pretypovanie

  • int(x) – vytvorí celé číslo. Pri prevode z float odstráni desatinnú časť smerom k nule; nezaokrúhľuje.
  • float(x) – vytvorí číslo typu float, napríklad z platného číselného reťazca.
  • str(x) – vytvorí textovú reprezentáciu hodnoty.
  • bool(x) – zistí pravdivostnú hodnotu objektu. Nulové čísla, prázdny reťazec a None sú nepravdivé; ostatné bežné neprázdne hodnoty sú pravdivé.
print(int(3.9))        # 3, nie 4
print(int(-3.9))       # -3
print(float("2.718"))  # 2.718
print(int("42"))       # 42
print(str(42))         # "42"
print(bool(0))         # False
print(bool(""))        # False
print(bool("False"))   # True: reťazec nie je prázdny

Prevod čísla s desatinnou časťou na celé číslo nie je zaokrúhlenie. Na zaokrúhľovanie slúži napríklad round(); pri reálnych číslach si všímaj aj obmedzenú presnosť reprezentácie typu float.

4. Chyby a strata informácií

  • Strata desatinnej časti: int(3.9) vráti 3.
  • Neplatný formát: int("abc") a float("dva") vyvolajú ValueError.
  • Nevhodný typ: niektoré prevody nepodporujú zadaný objekt a môžu vyvolať TypeError.
  • Presnosť: float používa konečnú binárnu presnosť, takže niektoré desatinné hodnoty sa neuložia úplne presne.

Samotné volanie konverznej funkcie nezaručuje, že vstup je platný. Pri údajoch od používateľa počítaj s neplatným formátom.

5. Bezpečné spracovanie číselného vstupu

Funkcia input() vždy vráti reťazec. Prevod preto vykonaj a prípadnú chybu ValueError zachyť:

text = input("Zadaj celé číslo: ")

try:
    cislo = int(text)
except ValueError:
    print("Neplatný formát. Zadaj celé číslo.")
else:
    print("Zadal si:", cislo)

Blok try obsahuje operáciu, ktorá môže zlyhať. Blok except ValueError rieši konkrétny očakávaný problém s formátom; else sa vykoná iba vtedy, keď prevod uspel.

6. Precvičenie

  1. Urči výsledok a typ výrazu 4 + 2.5.
  2. Vysvetli, prečo int(6.8) nevráti 7.
  3. Predpovedz výsledok bool("0") a zdôvodni ho.
  4. Doplň bezpečný prevod vstupu na desatinné číslo s ošetrením ValueError.
  5. Vysvetli rozdiel medzi chybou TypeError a ValueError na príkladoch z materiálu.
