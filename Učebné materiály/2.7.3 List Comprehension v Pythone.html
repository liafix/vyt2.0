Ciele hodiny

Žiak vysvetlí zápis [výraz for prvok in postupnosť], vytvorí nový zoznam transformáciou hodnôt, vyfiltruje prvky podmienkou a rozhodne, kedy je prehľadný cyklus vhodnejší než skrátený zápis.

1. Čo je list comprehension?

List comprehension (zoznamová komprehencia) je stručný spôsob, ako vytvoriť nový zoznam z hodnôt iterovateľného objektu, napríklad z iného zoznamu alebo rozsahu. Vnútri hranatých zátvoriek sa nachádza výraz, cyklus for a voliteľná podmienka.

Základný tvar

[výraz for prvok in postupnosť]
  • postupnosť je zdroj hodnôt, cez ktorý sa iteruje.
  • prvok postupne nadobúda každú hodnotu zo zdroja.
  • výraz určuje hodnotu, ktorá sa pridá do nového zoznamu.

2. Vytvorenie a transformácia hodnôt

Ak chceme vytvoriť druhé mocniny čísel, bežný cyklus postupne pridáva výsledok do nového zoznamu:

cisla = [1, 2, 3, 4, 5]
druhe_mocniny = []

for cislo in cisla:
    druhe_mocniny.append(cislo ** 2)

print(druhe_mocniny)  # [1, 4, 9, 16, 25]

Rovnaký postup možno zapísať pomocou list comprehension:

cisla = [1, 2, 3, 4, 5]
druhe_mocniny = [cislo ** 2 for cislo in cisla]

print(druhe_mocniny)  # [1, 4, 9, 16, 25]

Pre každý prvok zo zoznamu cisla sa vypočíta cislo ** 2 a výsledok sa uloží do nového zoznamu. Pôvodný zoznam sa pritom nemení.

Práca s inými postupnosťami

zdvojene = [cislo * 2 for cislo in range(1, 5)]
pismena = [znak.upper() for znak in "python"]

print(zdvojene)  # [2, 4, 6, 8]
print(pismena)   # ['P', 'Y', 'T', 'H', 'O', 'N']

3. Filtrovanie prvkov

Za časť for môžeme pridať podmienku if. Tá určuje, ktoré prvky sa do výsledného zoznamu vôbec dostanú:

cisla = [1, 2, 3, 4, 5, 6]
parne = [cislo for cislo in cisla if cislo % 2 == 0]

print(parne)  # [2, 4, 6]

Podmienka sa kontroluje pri každom prvku. Ak je pravdivá, výraz sa vyhodnotí a výsledok sa pridá. Ak je nepravdivá, prvok sa preskočí.

Filtrujeme texty

mena = ["Eva", "Alexander", "Mia", "Samuel"]
dlhe_mena = [meno for meno in mena if len(meno) > 4]

print(dlhe_mena)  # ['Alexander', 'Samuel']

4. Podmienka if/else vo výraze

Ak chceme vytvoriť výslednú hodnotu pre každý prvok, ale vybrať ju podľa podmienky, použijeme podmienkový výraz hodnota_ak_plati if podmienka else ina_hodnota. Rozdiel oproti filtru je dôležitý: tu sa do výsledku dostane každý prvok, len sa môže zmeniť jeho výsledná hodnota.

cisla = [1, 2, 3, 4]
popisy = ["párne" if cislo % 2 == 0 else "nepárne" for cislo in cisla]

print(popisy)  # ['nepárne', 'párne', 'nepárne', 'párne']

5. Filter alebo podmienkový výraz?

ZápisÚčinokPočet výsledkov
[x for x in cisla if x > 0]Do výsledku vyberie iba kladné hodnoty.Môže byť menší ako pôvodný zoznam.
["kladné" if x > 0 else "ostatné" for x in cisla]Vytvorí označenie pre každý prvok.Rovnaký ako počet prvkov vstupu.

6. Zhrnutie syntaxe

# transformácia každého prvku
[výraz for prvok in postupnosť]

# výber iba prvkov spĺňajúcich podmienku
[výraz for prvok in postupnosť if podmienka]

# iná výsledná hodnota podľa podmienky
[hodnota_ak_plati if podmienka else ina_hodnota
 for prvok in postupnosť]

Pri filtri if za cyklom nie je časť else. Pri podmienkovom výraze je potrebné uviesť if aj else a celý výraz sa nachádza pred cyklom for.

7. Čitateľnosť a časté chyby

  • Nezabudni na hranaté zátvorky – výsledkom je nový zoznam.
  • Vo výraze používaj správnu premennú prvku, napríklad cislo, ktorá je uvedená v časti for cislo in cisla.
  • Filter if napíš za časť for; podmienkový výraz s if ... else patrí pred ňu.
  • Nepoužívaj komprehenciu na vedľajšie účinky, napríklad na volanie print(). Na také úlohy je zrozumiteľnejší bežný cyklus.
  • Ak je výraz príliš dlhý, obsahuje viac krokov alebo sa ťažko číta, použi obyčajný cyklus for.

List comprehension vytvára celý zoznam v pamäti. Pri veľmi veľkom množstve hodnôt preto zváž, či je vytvorenie celého zoznamu potrebné.

8. Precvičenie

  1. Zoznam teploty = [12, 18, 21, 9] premeň na nový zoznam teplôt vo stupňoch Fahrenheita podľa vzorca F = C * 9 / 5 + 32.
  2. Zo zoznamu čísel [3, 8, 11, 14, 17, 20] vytvor zoznam čísel väčších ako 10.
  3. Z textu "programovanie" vytvor zoznam samohlások, ktoré sa v ňom nachádzajú.
  4. Pre čísla od 1 do 5 vytvor zoznam textov "párne" alebo "nepárne" pomocou podmienkového výrazu.
  5. Vyber jednu úlohu a prepíš ju aj bežným cyklom. Ktorý zápis sa ti ľahšie číta?
Poznámka pre učiteľa: Pri prvom príklade porovnajte cyklus s append() a komprehenciu krok za krokom. Žiaci nech odlíšia filter if od podmienkového výrazu if/else podľa toho, či sa prvok vynechá, alebo sa mu priradí iná hodnota. Uprednostnite zrozumiteľnosť pred čo najkratším zápisom; vnorené komprehencie nechajte ako rozširujúcu tému.
