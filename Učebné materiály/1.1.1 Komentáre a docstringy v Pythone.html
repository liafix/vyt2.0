1.1.1 Komentáre a docstringy v Pythone

Úvod do programovania Pracovný materiál

Ciele hodiny

  • Vysvetliť, na čo slúžia komentáre v zdrojovom kóde.
  • Napísať jednoriadkový aj viacriadkový komentár.
  • Rozlíšiť komentár od dokumentačného reťazca (docstringu).
  • Vytvoriť a zobraziť dokumentáciu funkcie, triedy alebo modulu.

1. Komentáre v Pythone

Komentár je poznámka pre človeka, ktorý číta alebo upravuje kód. Python ignoruje text od znaku # po koniec daného riadka. Komentár môže byť samostatný riadok alebo krátka poznámka za príkazom.

# Vypíš pozdrav používateľovi
print("Ahoj!")  # Komentár za príkazom

Používaj komentáre na vysvetlenie dôvodu alebo dôležitého rozhodnutia, nie na opakovanie toho, čo už jasne hovorí samotný kód.

Viacriadkové komentáre

Python nemá osobitnú syntax pre blokový komentár. Viacriadkovú poznámku zapíš pomocou znaku # na každom riadku:

# Tento postup najprv načíta vstupy.
# Potom vypočíta výsledok.
# Nakoniec ho zobrazí.
Presné rozlíšenie: Trojité úvodzovky vytvárajú viacriadkový reťazec, nie komentár. Samostatný reťazec, ktorý sa nikam nepriradí, sa po vyhodnotení zahodí, ale na bežné komentovanie sa používa #. Trojité úvodzovky sú vhodné najmä pre docstringy.

2. Docstring – dokumentačný reťazec

Docstring je reťazec, ktorý sa nachádza ako prvý príkaz v module, funkcii alebo triede. Python ho priradí do atribútu __doc__; dokumentáciu možno zobraziť cez help(). Bežne sa píše v trojitých dvojitých úvodzovkách.

Docstring funkcie

def greet(name: str, excited: bool = False) -> str:
    """Vráti pozdrav pre osobu so zadaným menom.

    Args:
        name: Meno osoby, ktorú pozdravujeme.
        excited: Ak je True, pridá na koniec výkričník.

    Returns:
        Pozdrav ako text.

    Examples:
        >>> greet("Dušan")
        'Ahoj, Dušan'
        >>> greet("Dušan", True)
        'Ahoj, Dušan!'
    """
    ending = "!" if excited else ""
    return f"Ahoj, {name}{ending}"

print(greet("Dušan"))
help(greet)

Docstring patrí hneď za hlavičku funkcie, ešte pred jej bežné príkazy. V príklade funkcia vracia text pomocou return; print() ho následne zobrazí. V príkladoch docstringu sú uvedené vstupy, návratová hodnota a ukážkové volania.

Docstring triedy

class GameObject:
    """Predstavuje objekt v jednoduchej hre.

    Attributes:
        name: Názov objektu.
        health: Počet bodov zdravia.
        attack: Sila útoku.
    """

    def __init__(self, name: str, health: int, attack: int):
        self.name = name
        self.health = health
        self.attack = attack

help(GameObject)

Docstring vstavaného objektu

Aj vstavané funkcie majú dokumentáciu. Vyskúšaj:

print(print.__doc__)
help(print)

Výpis opisuje parametre funkcie print(), napríklad oddeľovač sep, koniec výstupu end a cieľový výstupný prúd file.

3. Rýchle porovnanie

  • # komentár – poznámka v zdrojovom kóde; Python ju ignoruje.
  • """reťazec""" – viacriadkový reťazec, nie špeciálny blokový komentár.
  • Docstring – reťazec na prvom mieste v module, triede alebo funkcii; dostupný cez __doc__ a help().

4. Krátke precvičenie

  1. Doplň komentár, ktorý vysvetlí, čo robí tvoj program.
  2. Vytvor funkciu na výpočet obvodu štvorca a pridaj jej docstring s opisom parametra a návratovej hodnoty.
  3. Vyskúšaj help(tvoja_funkcia) a print(tvoja_funkcia.__doc__).
  4. Rozhodni, či je daná poznámka komentár, obyčajný reťazec alebo docstring.
