2.2.1 Premenné, dátové typy a operácie v Pythone

Ťahák Základy Pythonu

Ciele

Po preštudovaní materiálu žiak vysvetlí, čo je premenná, rozpozná základné dátové typy, použije aritmetické, porovnávacie a logické operátory a načíta a vypíše jednoduché údaje.

1. Premenná a priradenie

Premenná je pomenovanie, cez ktoré v programe pracujeme s hodnotou. Operátor = priradí hodnotu do premennej; neznamená matematickú rovnosť. Python určí typ podľa priradenej hodnoty a ten sa môže počas behu programu zmeniť.

vek = 16
meno = "Alica"
teplota = 21.5
print(meno, vek, teplota)

Názov premennej začína písmenom alebo podčiarkovníkom, môže obsahovať číslice (nie však na začiatku) a rozlišuje veľké a malé písmená. Používaj výstižné názvy, napríklad pocet_bodov. Kľúčové slová Pythonu, napríklad if a for, nie sú vhodné názvy premenných.

2. Základné dátové typy

  • int – celé čísla, napríklad -4, 0, 25.
  • float – čísla s desatinnou časťou; v kóde sa používa bodka, napríklad 3.14.
  • str – textový reťazec v úvodzovkách, napríklad "Ahoj".
  • bool – logická hodnota True alebo False.

Typ hodnoty môžeme preskúmať pomocou type():

print(type(25))       # int
print(type(3.14))     # float
print(type("Ahoj"))   # str
print(type(True))     # bool

3. Operácie s číslami

Základné aritmetické operátory sú sčítanie +, odčítanie -, násobenie *, delenie /, celočíselné delenie //, zvyšok po delení % a umocňovanie **. Zátvorky určujú poradie výpočtu.

a = 17
b = 5
print(a + b)   # 22
print(a / b)   # 3.4
print(a // b)  # 3
print(a % b)   # 2
print(2 ** 3)  # 8

Operátor / vracia podiel typu float. Pri kladných číslach // dáva celočíselnú časť podielu a % zvyšok; pri záporných číslach sa výsledok riadi matematickou definíciou delenia nadol.

4. Porovnávacie a logické operátory

Porovnania ==, !=, <, >, <= a >= vracajú hodnotu typu bool. Pozor: = priraďuje, zatiaľ čo == porovnáva. Logické operátory and, or a not kombinujú alebo obracajú podmienky.

vek = 16
plnoletost = vek >= 18
ma_vstupenku = True
moze_vstupit = plnoletost and ma_vstupenku
print(plnoletost)    # False
print(moze_vstupit)  # False

5. Vstup a výstup

input() načíta text od používateľa a print() vypíše hodnoty. Keď používateľ zadá číslo, výsledok input() je stále text (str); prevod na číselný typ sa vysvetľuje v podtéme 2.2.2.

meno = input("Ako sa voláš? ")
print("Ahoj,", meno)

6. Precvičenie

  1. Vytvor premenné pre svoje meno, vek a výšku; vypíš ich hodnoty aj typy.
  2. Načítaj dve čísla a vypíš ich súčet, súčin a zvyšok po delení.
  3. Vysvetli rozdiel medzi výrazmi pocet = 5 a pocet == 5.
  4. Napíš logický výraz, ktorý je pravdivý, ak číslo leží v rozsahu od 1 do 10 vrátane.
